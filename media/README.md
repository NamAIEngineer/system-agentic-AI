# System Agentic AI introduction source

Reproducible Remotion composition for the 54-second English introduction.

```sh
npm ci
REMOTION_BROWSER=/path/to/chromium npm run render
```

The renderer writes `out/system-agentic-intro-1080p.mp4` plus stills when invoked with `node render-system-agentic.mjs stills`. Generated output and local dependencies stay ignored. The source is a motion composition, not a claim that every panel is a live UI capture: the film labels illustrative geometry and grounds shown JSON values in `evidence/`.
